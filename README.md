## 🌸 The Vision
**The Petal & Bloom** is not merely an e-commerce storefront; it is a digital gallery designed to mirror the slow, intentional process of artisanal crochet. The platform transforms the act of shopping into a curated experience, blending the precision of modern software with the softness of handmade art.

Guided by a **"Sophisticated Minimalist"** philosophy, the atelier emphasizes whitespace, refined typography, and a muted botanical palette, ensuring that the craftsmanship of every piece remains the central focus.

## ✨ The Experience

### The Gallery
A seamless, high-performance interface where each botanical piece is presented as a work of art. The experience is defined by:
- **Curated Narrative**: Intentional flows that guide the visitor from discovery to desire.
- **Tactile Digitality**: Subtle micro-interactions and smooth reveals that mimic the unfolding of a flower.
- **The Bloom Bag**: A refined approach to the shopping cart, focusing on the curation of a personal collection.

### The Studio Engine
Behind the minimalist facade lies a powerful, dynamic infrastructure:
- **Dynamic Catalog**: A real-time synchronization between the storefront and the studio database, allowing for fluid updates to categories and navigation.
- **Gift Concierge**: Integrated WhatsApp communication channels that bridge the gap between digital browsing and personalized artisanal consultation.
- **Admin Suite**: A professional management portal that allows the studio owner to orchestrate the entire gallery without touching a single line of code.

## 🛠 Technical Architecture

The atelier is built upon a modern, scalable stack designed for speed and elegance.

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | React 18 + TypeScript | Type-safe, component-driven UI development. |
| **Build Tool** | Vite | Ultra-fast HMR and optimized production bundling. |
| **Styling** | Tailwind CSS | Utility-first design implementing a custom luxury design system. |
| **Backend** | Supabase (PostgreSQL) | Real-time data orchestration, authentication, and asset storage. |
| **Routing** | React Router DOM | SPA architecture for fluid, zero-reload transitions. |

## 🚀 Development

### Quick Start
```bash
# Install dependencies
npm install

# Launch the studio environment
npm run dev

# Build for production
npm run build
```

The visual identity is anchored in a custom palette:

- **Deep Slate Green** (`#3C473E`) — The grounding ink.
- **Muted Blush** (`#BFA3A3`) — The accent of softness.
- **Silver Sage** (`#A3B18A`) — The touch of nature.
